# Bangla Sticker

An Android app with a fixed set of prebuilt **Bangla stickers** that you can use
in messaging apps. It ships as a WhatsApp third‑party sticker pack and also lets
you share any sticker to Messenger, Telegram, or any other app through the
Android share sheet.

## What's inside

- **12 prebuilt Bangla stickers** (512×512 WebP, WhatsApp‑compliant) such as
  ভালোবাসা, ধন্যবাদ, শুভ সকাল, দারুণ! …
- A `StickerContentProvider` implementing WhatsApp's
  [third‑party sticker API](https://github.com/WhatsApp/stickers), so the pack
  can be added directly to WhatsApp with one tap.
- A home screen that previews the pack, an **Add to WhatsApp** button, and
  tap‑to‑share for every other app.

## Getting the APK

This repo builds a debug APK automatically with GitHub Actions — no local
Android toolchain required:

1. Push to the repo (or open the **Actions** tab and run the **Build APK**
   workflow via *Run workflow*).
2. Open the finished workflow run and download the **`bangla-sticker-debug-apk`**
   artifact.
3. Unzip it to get `app-debug.apk`, copy it to your phone, and install it
   (you may need to allow "Install from unknown sources").

### Build locally instead

With Android Studio (or the Android SDK + JDK 17) installed:

```bash
./gradlew assembleDebug
# output: app/build/outputs/apk/debug/app-debug.apk
```

> Note: this project cannot be compiled inside the Claude Code web container
> because Google's Maven repository (`dl.google.com` / `maven.google.com`) is
> not reachable there. That is why the APK is produced via GitHub Actions or a
> local machine.

## Using the stickers

- **WhatsApp:** open the app and tap **Add to WhatsApp**. The pack then appears
  in WhatsApp's sticker tray.
- **Messenger / Telegram / others:** tap any sticker in the app and pick the
  target app from the share sheet. (Messenger has no public sticker‑pack API,
  so stickers are sent as images via sharing.)

## Your own stickers

Tap **+ Add your own sticker** to import any photo from your device. The app
scales it to a 512×512 WebP sticker and saves it privately on the device under
**My Stickers**, so you can reuse it anytime:

- **Tap** a custom sticker to share it to Messenger, Telegram, WhatsApp chat, etc.
- **Long-press** a custom sticker to delete it.
- Once you have **3 or more** custom stickers, tap **Add My Stickers to WhatsApp**
  to load them into WhatsApp's sticker tray. WhatsApp caches packs, so after
  adding or removing custom stickers, tap that button again to refresh.

Custom stickers live in the app's private storage, so uninstalling the app
removes them.

## Customizing / regenerating stickers

Sticker images, the tray icon, the app launcher icon, and `contents.json` are
generated by [`tools/generate_stickers.py`](tools/generate_stickers.py).

```bash
pip install Pillow            # must be built with raqm for Bangla shaping
python3 tools/generate_stickers.py
```

Edit the `STICKERS` list in that script to change the words, colors, or emoji.
The Bengali font used is **Hind Siliguri** (SIL Open Font License), vendored in
`tools/`.

## Project layout

```
app/src/main/
  assets/contents.json              pack + sticker metadata (WhatsApp format)
  assets/bangla_pack_1/*.webp       sticker images + tray icon
  java/com/banglasticker/app/       app + StickerContentProvider
  res/                              layouts, strings, theme, launcher icons
tools/generate_stickers.py          regenerate all image assets
.github/workflows/build-apk.yml     CI that builds and uploads the APK
```

## Requirements / constraints (WhatsApp)

- Each pack must contain 3–30 stickers (this pack has 12).
- Static stickers: 512×512 WebP, ≤ 100 KB each. Tray icon: 96×96, ≤ 50 KB.
- Every sticker is tagged with at least one emoji for search.
